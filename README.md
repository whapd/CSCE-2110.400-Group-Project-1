Campus student resource management system.

This program manages reservations and availability for student resources.

Main menu: Provides a list of functionalities to the user.
To select an option, enter the respective number and press enter.

This program has many separate files, listed below:

Reservation: class that exists to create Reservation objects.

Resource Manager: Loads, stores, and displays campus resources.

Reservation Manager and Reservation System: performs reservation management tasks such as creation and input validation.

Cancellation tracker: manages cancelled reservations. Logs cancellations in a stack. Can display cancelled reservations and restore the latest cancellation.
